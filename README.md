# LestaStart Battleship Matchmaking

## Краткое описание

Микросервис, отвечающий за распределение игроков по матчам.
Игроки подключаются по WebSocket к сервису.

## Стак

- Golang
- Docker
- Caddy
- Justfile

## Запуск

В justfile описывается, как можно скомпилировать и запустить проекте.
При запуске сервис будет доступен на указаном адресе.
Caddy постарается при отсутствие добыть сертификат.

### Опции

```
HOST_ADDR=localhost - адрес, на котором будет доступен сервис.

BACKEND_PORT=8080 - порт, на котором будет доступен сервис.
```
